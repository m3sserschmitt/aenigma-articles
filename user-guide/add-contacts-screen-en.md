## The New Contact Creation Screen

On this screen, the application provides the user with a connection QR code that
can be easily shared with other users of the application. Using the
button in the bottom-right corner of the screen, the user can switch between share mode
and scanner mode. Additionally, the app provides the ability to create
connection links that can be sent to other users, even through
other communication apps. In general, these can be used only once, unless the user
changes this option from the secondary menu.

![alt text](https://articles.aenigma.ro/user-guide/images/add-contacts-screen.png)

1. The access button for information.
2. The button for showing/hiding the secondary menu.
3. The button for enabling/disabling ephemeral links. When this
option is active, all connection links will be valid for a single use. Otherwise,
the server will delete the link after a preset period of time.
4. The export button for the QR code. This can be shared with other applications.
5. The reset button for the username. This will be visible to the people
you share links or QR codes with.
6. The QR code that can be scanned by other application users to create
a contact.
7. The button for sharing the connection link with other users.
8. The button for entering a connection link received from another user.
9. The button for switching between the QR code and the QR code scanner.
10. The navigation button to go back to the previous screen.
