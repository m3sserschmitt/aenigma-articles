## The Chat Screen

On this screen the user can access the entire conversation with a specific contact.
Simple text messages or files of any type can be sent. Here the user
can also perform a series of operations on the contact, such as renaming or
sharing it with other contacts. Deleting the conversation will cause the deletion of all
messages for all participants.

![alt text](https://articles.aenigma.ro/user-guide/images/chat-screen.png)

1. The resynchronization button with the server. The connection will be rebuilt from the start.
This can be used in situations where message delivery is delayed or completely
failed.
2. The search button for text messages. The search bar will become visible and
the user will be able to search for specific text messages.
3. The access button for information.
4. The menu for showing/hiding the secondary menu.
5. Renaming the contact.
6. Sharing the contact with other contacts in the application or through other
communication apps.
7. Completely deleting all messages. The conversation will be deleted for all
participants.
8. The file attachment button. There is a limit on the number of files and
their size (e.g., a maximum of 25 files not exceeding 25MB). These
restrictions may differ from one version to another.
9. The message sending button.
10. The navigation button to go back to the previous screen.

### Selection Mode

By long-pressing on any of the conversation's messages, a series of
actions at the individual message level will become visible, as follows:

![alt text](https://articles.aenigma.ro/user-guide/images/chat-screen-selection-mode.png)

1. The button for exiting selection mode.
2. The button for replying to the selected message.
3. The button for deleting the selected message.
4. The message selection indicator. In selection mode, simply tapping a message
will cause it to be selected or, as appropriate, deselected.
5. The file attachment button.
6. The message sending button.
