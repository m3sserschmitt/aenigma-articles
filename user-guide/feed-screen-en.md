## The News Feed Screen

On this screen the user can view files and articles shared by other
users. Only files and articles shared within a certain period of time
will be visible, e.g., the last 3 months. The length of this period may vary from one version
to another. Given the distributed nature of the system, the user's contacts will
only have access to the files and articles shared by them *after* they connect via
QR code or link with them. Since posts are not stored in any centralized location,
users cannot access a post history similar to what
other social networking apps offer. There is no notion of a ***profile***.

**Note**: *If two users connected, for example, two months ago, they
will not be able to see each other's posts from two years ago. Only what has been shared in
the last two months will be visible.*

Users can create posts which are then shared exclusively with their
contact list.

1. The button for accessing the section for creating a new post.
2. The button for regenerating the news feed. Sources will be queried and the list will be
updated with the newest information.
3. The access button for information.
4. The action buttons for files attached to posts. These allow forwarding
to the user's contacts, sharing, or opening through other applications.
5. The handle used to access/dismiss, by swiping, the section for creating a new
post.

### The Post Creation Section

![alt text](https://articles.aenigma.ro/user-guide/images/feed-screen-story-bottom-sheet.png)

1. The access button for information.
2. The post title.
3. The post preview. This will be visible in the news feed.
4. The file attachment button. Photos or any other
type of document can optionally be attached.
5. The post content. This will only be visible after users access
the article from the news feed. This field supports Markdown text formatting.
For more information, visit
[https://www.markdownguide.org/basic-syntax/](https://www.markdownguide.org/basic-syntax/).
6. The post button. Only the user's contacts will receive the post.
7. Allows navigation to the post editing section.
8. Allows navigation to the cover preview section, i.e., how the
post will look in the news feed.
9. Allows navigation to the formatted content preview section.
10. The handle used to access/dismiss, by swiping, the section for creating a
new post.
